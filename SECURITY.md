# Security policy

## Supported versions

Only the latest release is supported with security fixes.

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Contact the maintainer privately through GitHub Security Advisories ("Report a vulnerability" in the Security tab) or open a minimal issue asking for a private contact channel.

Please include:

- affected version
- reproduction steps
- impact
- any suggested fix

## Scope

The application processes local image files and writes user-selected export files. The optional elevated helper copies an already-rendered file to a user-selected destination after UAC consent. Reports about unintended file access, unsafe path handling, or privilege escalation are especially welcome.
